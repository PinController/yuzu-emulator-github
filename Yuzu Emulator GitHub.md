## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Game won't boot** | Update firmware + keys |
| **Low FPS** | Switch to Vulkan |
| **Black screen** | Disable anti-aliasing |
| **Controller not detected** | Use SDL input |
| **Audio stutter** | Increase buffer |
| **Shader compile stutter** | Enable async shaders |
